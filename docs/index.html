svgstore

Combine multiple SVG files into one sprite using <symbol> elements.

Quick start

Install the package and add SVG files to a sprite:

npm install @tomasvn/svgstore
const svgstore = require('@tomasvn/svgstore');
const fs = require('fs');

const sprite = svgstore()
  .add('icon', fs.readFileSync('./icon.svg', 'utf8'));

fs.writeFileSync('./sprite.svg', sprite);
